    How Ghost Mode decides what to flag

    Each warning sign adds weight (dots). Signs from adults you haven't approved count in full. From kids their own age they count for less than half, so "don't tell anyone about the party" won't set anything off. Disguised spellings like "sn4p" and emoji like 📸 count too.
